# Magatama branding

Artwork by BittahBandit1 for Magatama.

- `magatama-logo-light.png`, `magatama-logo-dark.png`, `magatama-logo-glow.png`: the logos as drawn (2048x2048).
- `magatama-wordmark.png`: the dark logo's lettering on a transparent background (the launcher and installer
  windows show it).
- `magatama-icon-1024.png`: the app icon (macOS grid: an 824-pixel rounded square in a 1024 canvas), from the dark
  logo. `scripts/magatama_macos_release.sh` turns it into `Magatama.icns` for Magatama.app and the installer.

Made from the logos with `python3 assets/branding/make_icons.py`.
